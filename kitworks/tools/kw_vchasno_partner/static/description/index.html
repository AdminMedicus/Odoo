Vchasno Partner


Extends Partner functionality with Vchasno document management capabilities. This module allows you to send documents directly to partners via Vchasno electronic document management system, track document status, and automatically detect partners for incoming documents.

Key features include:

  • Send documents to partners via Vchasno
  • Track partner documents status in real-time
  • Automatic partner detection for documents based on EDRPOU/IPN
  • Partner-specific document wizard with customizable fields
  • Document history per partner

Configuration

1. Mark Partners as Vchasno Users:

For each partner you want to send documents to:

  • Open the partner form
  • Enable "Vchasno User" checkbox
  • Ensure VAT (EDRPOU/IPN) and Email fields are filled
2. Sending Documents:

On the partner form, you'll find options to send documents directly to that partner through Vchasno.

Features Details

  • Partner Integration:
    • Vchasno user flag on partner form
    • Direct document sending from partner
    • View all documents for specific partner
  • Document Wizard:
    • Pre-filled partner information
    • Automatic EDRPOU/email detection
    • Document type selection
  • Automatic Detection:
    • Auto-match incoming documents to partners
    • Search by EDRPOU/IPN
    • Fallback search by company name

Dependencies

This module requires:

  • kw_vchasno - Core Vchasno integration module
