# Vchasno Bundle

Complete integration package for Vchasno electronic document management system.

## Description

This bundle module installs all Vchasno modules at once:
- **kw_vchasno** - Core Vchasno integration
- **kw_vchasno_partner** - Partner integration
- **kw_vchasno_account** - Account/Invoice integration
- **kw_vchasno_sale** - Sale/Pro-forma integration

## Installation

Simply install this module to get all Vchasno functionality.

## Configuration

After installation, configure Vchasno API keys in Settings → Vchasno → API Keys.

## Features

- Complete API integration with Vchasno
- Electronic document management
- Digital signatures support
- Send invoices and pro-forma documents
- Track document status
- Partner document management
