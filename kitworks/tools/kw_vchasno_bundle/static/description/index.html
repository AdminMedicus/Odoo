Vchasno Integration


Complete integration package for Vchasno - Ukrainian electronic document management system. This bundle installs all Vchasno modules to provide full EDI (Electronic Data Interchange) functionality in Odoo.

Key features include:

  • API Integration: Direct connection with Vchasno API for real-time document exchange
  • Electronic Signatures: Support for qualified electronic signatures
  • Document Management: Send, receive and track documents
  • Invoice Integration: Send invoices directly from Odoo
  • Partner Management: Automatic partner detection and document routing
  • Status Tracking: Real-time tracking of document status

Included Modules

kw_vchasno

Core module providing:

  • API connector and authentication
  • Document model and management
  • Category and status tracking
  • Automatic synchronization
  • Electronic signature support

kw_vchasno_partner

Partner integration providing:

  • Partner-specific document sending
  • Automatic partner detection
  • Document history per partner

kw_vchasno_account

Account module integration:

  • Send invoices via Vchasno
  • Batch invoice sending
  • Invoice status tracking
  • Electronic invoice signing

kw_vchasno_sale

Sale module integration:

  • Send pro-forma invoices/sale orders
  • Configure signature order
  • Multiple recipient support

Configuration

1. Install the Module:

Install this bundle module to get all Vchasno functionality at once.

2. Configure API Credentials:

Navigate to Settings → Vchasno → API Keys and create a new API key with your Vchasno credentials:

  • Name: Descriptive name for the connection
  • Token: Your Vchasno API token
  • EDRPOU Owner: Your company's EDRPOU/IPN
  • Email Owner: Your company email
3. Configure Partners:

For each partner you want to send documents to:

  • Open the partner form
  • Enable "Vchasno User" checkbox
  • Fill in VAT (EDRPOU/IPN) and Email

Usage

Sending Invoices:

  1. Create an invoice as usual
  2. Click "Send Invoices" button
  3. Enable "Send in Vchasno" checkbox
  4. Select Vchasno API key
  5. Click "Send Vchasno" button

Sending Pro-Forma/Sale Orders:

  1. Open a sale order
  2. Click "Send by Email" button
  3. Enable "Send in Vchasno" checkbox
  4. Select Vchasno API key
  5. Configure signature settings if needed
  6. Click send button

Tracking Documents:

Navigate to Vchasno → Documents to see all sent and received documents with their current status.
