Vchasno


Core module for integration with Vchasno - Ukrainian electronic document management system. Provides API connectivity, document management, and electronic signature support for seamless EDI (Electronic Data Interchange) operations.

Key features include:

  • API Integration: Direct connection with Vchasno API for real-time document exchange
  • Document Management: Comprehensive document handling and storage
  • Electronic Signatures: Support for qualified electronic signatures
  • Status Tracking: Real-time document status monitoring
  • Automatic Synchronization: Scheduled document updates and downloads
  • Category Management: Organize documents by customizable categories

Configuration

1. Create API Key:

Navigate to Settings → Vchasno → API Keys and create a new API key:

  • Name: Descriptive name for the connection
  • Token: Your Vchasno API token from vchasno.ua
  • EDRPOU Owner: Your company's EDRPOU or IPN
  • Email Owner: Your company email for notifications
  • Company: Select the Odoo company for this connection
2. Configure Document Categories:

Access Vchasno → Catalog → Category List to view and manage document categories synchronized from Vchasno.

3. Set Up Cron Jobs:

The module includes scheduled actions for automatic document synchronization:

  • Update Documents: Syncs incoming and outgoing documents
  • Update Document Info: Refreshes document status and details
