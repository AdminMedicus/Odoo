# Vchasno

Core module for integration with Vchasno electronic document management system.

## Features

- API integration with Vchasno
- Document management
- Electronic signatures support
- Document status tracking
- Automatic document synchronization

## Configuration

1. Go to Settings → Vchasno → API Keys
2. Create new API key with your Vchasno credentials
3. Configure document categories and statuses
