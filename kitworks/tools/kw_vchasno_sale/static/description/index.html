Vchasno Sale Pro-Forma


Extends Sale module with ability to send pro-forma invoices and sale orders through Vchasno electronic document management system. This module allows you to send sale documents with electronic signatures directly from the sale order form.

Key features include:

  • Send sale orders/pro-forma invoices via Vchasno
  • Electronic document signing with qualified signatures
  • Configure signature order (owner or recipient signs first)
  • Multiple recipients support for single document
  • Integration with standard Odoo email composer

Configuration

Prerequisites:
  • kw_vchasno module must be installed and configured
  • kw_vchasno_partner module must be installed
  • Vchasno API key must be configured
  • Partners must be marked as Vchasno users
Usage:
  1. Open a sale order
  2. Click "Send by Email" button
  3. In the composer wizard, enable "Send in Vchasno" checkbox
  4. Select your Vchasno API key
  5. Configure "First Sign By" option:
    • Owner: Your company signs first, then sends to recipient
    • Recipient: Recipient signs first, then returns to owner
  6. Select recipients (partners)
  7. Choose attachments to send
  8. Click send button

Features Details

  • Signature Workflow:
    • Configure who signs first (owner or recipient)
    • Flexible signing order for different scenarios
    • Track signature status
  • Multiple Recipients:
    • Send same document to multiple partners
    • Each partner gets individual copy
    • Separate tracking for each recipient
  • Document Handling:
    • Automatic PDF attachment
    • Support for multiple attachments
    • Document categorization (default: category 13)
    • Amount field populated from sale order total
  • Integration:
    • Seamless integration with Odoo mail composer
    • Works with standard email sending workflow
    • Preserves all Odoo email features

Use Cases

Scenario 1: Pro-forma Invoice

When you need customer approval before creating final invoice:

  1. Create sale order with "Recipient" as first signer
  2. Send pro-forma via Vchasno
  3. Customer reviews and signs
  4. Document returns to you
  5. You sign to confirm
Scenario 2: Contract/Agreement

When you need to send signed document to partner:

  1. Create sale order with "Owner" as first signer
  2. You sign the document first
  3. Send signed document via Vchasno
  4. Partner receives already signed document
  5. Partner signs to accept

Dependencies

This module requires:

  • kw_vchasno_partner - Vchasno Partner integration
  • sale - Odoo Sales module
