# Vchasno Sale Pro-Forma

Extends Sale module with ability to send pro-forma invoices through Vchasno.

## Features

- Send sale orders/pro-forma invoices via Vchasno
- Electronic document signing
- Configure signature order (owner/recipient first)
- Multiple recipients support

## Dependencies

- kw_vchasno_partner
- sale
