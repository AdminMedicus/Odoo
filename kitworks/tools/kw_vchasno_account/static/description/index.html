Vchasno Account


Extends Account module with ability to send invoices through Vchasno electronic document management system. This module integrates the invoice sending workflow with Vchasno, allowing you to send invoices with electronic signatures directly from Odoo.

Key features include:

  • Send invoices via Vchasno with one click
  • Electronic invoice signing with qualified signatures
  • Track invoice delivery status in real-time
  • Batch invoice sending support for multiple invoices at once
  • Integration with standard Odoo invoice sending workflow

Configuration

Prerequisites:
  • kw_vchasno module must be installed and configured
  • kw_vchasno_partner module must be installed
  • Vchasno API key must be configured
  • Partners must be marked as Vchasno users
Usage:
  1. Open an invoice
  2. Click "Send Invoices" button
  3. In the send wizard, enable "Send in Vchasno" checkbox
  4. Select your Vchasno API key
  5. Click "Send Vchasno" button
Batch Sending:

You can also send multiple invoices at once:

  1. Select multiple invoices from the list view
  2. Choose "Send Invoices" from the action menu
  3. Follow the same steps as for single invoice

Features Details

  • Invoice Sending:
    • Integrated with standard Odoo send wizard
    • Automatic document preparation
    • Attachment handling
    • Category assignment (default: category 2)
  • Batch Operations:
    • Send multiple invoices at once
    • Progress tracking
    • Error handling for individual failures
  • Status Tracking:
    • View sent invoices in Vchasno documents
    • Track delivery and signing status
    • Receive notifications on status changes

Dependencies

This module requires:

  • kw_vchasno_partner - Vchasno Partner integration
  • account - Odoo Accounting module
